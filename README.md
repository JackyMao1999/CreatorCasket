# 🌍 世界盒子 Web版 — 上帝模拟器

基于浏览器 Canvas 的像素风**上帝沙盒游戏**。创造世界、孕育文明、降下天灾、改写历史 — 一切由你掌控。**零依赖，双击即玩。**

---

## 🚀 快速开始

```bash
# 方式 1：直接双击 index.html（推荐，无需任何工具）

# 方式 2：启动本地服务器
cd /home/ubuntu/dev/worldbox
python3 -m http.server 8931
# 浏览器打开 http://localhost:8931
```

> 无需 Node.js、无需 npm install、无需任何框架。纯 HTML + CSS + JS 即可运行。

## 🎮 游戏系统

### 🗺️ 世界与地形

9 种地块类型，通过**分形噪声**算法生成群岛地貌，四周天然深海边缘：

| 地块 | 说明 |
|------|------|
| 🌊 深海 | 不可通行，边缘衰减生成 |
| 💧 浅海 | 文明单位可游泳（45% 速度） |
| 🏖️ 沙地 | 水陆交界，可建农田 |
| 🌿 草地 | 可建村庄，森林自然蔓延 |
| 🌲 森林 | 易燃，火焰可跨草木蔓延 |
| ⛰️ 丘陵 | 可通行，抬升/下沉的中间态 |
| 🏔️ 高山 | 不可通行，阻挡单位移动 |
| 🌋 熔岩 | 冷却成山，点燃周围，持续伤害 |
| 🔥 焦土 | 燃烧后的废墟，随时间回复草地 |

**环境模拟**：火焰蔓延、雨天灭火、熔岩冷却成山、植被自然恢复、森林扩散。

### 🏛️ 文明模拟

#### 村庄
- 村民自动在草地上**建立村庄**（检测周围 12 格内无重复）
- 村庄扩张：建造房屋→容纳人口→开垦农田→生产食物→半径成长
- 建筑连接**自动修路**（房屋/主殿到中心铺路，浅海铺**木桥**）
- **领地制度**：每个村庄通过洪泛算法划分领地（彩色描边显示）
- 人满自动派出**开拓者**远行建新村
- 文明单位可**游泳**跨越水域（浅海减至 45% 速，深海 22% 速 + 缓慢溺水）

#### 王国
- 同族村庄邻近时**合并成王国**（随机中文国名如「苍狼帝国」「翡翠林地」）
- 王国之间每 150 tick 进行外交判定：**宣战** / **议和** / **结盟**
- 战士自动向敌国村庄进军，攻击敌方单位和建筑
- 村庄主殿被摧毁则**村庄灭亡**（农田荒废、村名退化为流民）

#### 外交与同盟
- **关系值**（−100~+100）：宣战/和平/同盟/贸易/同族等多种行为影响
- **政体**：5 种随机分配（君主制/部落制/神权制/共和制/龙血帝国），影响宣战概率
- **同盟**：双向关系（最多 3 个盟友），关系≥+50 可结盟
- **联军**：盟友的敌人即我的敌人，战士自动支援盟友前线
- **背刺**：向盟友宣战时自动断交 → `💔 背叛了同盟`
- **联军**：盟友的敌人即我的敌人，战士自动支援盟友前线
- **背刺**：向盟友宣战时自动断交 → `💔 背叛了同盟`
- **自然瓦解**：无共同敌人 + 异族 → 概率退盟

#### 叛乱
- 村庄**不满度**（0~100）随食物短缺/拥挤/瘟疫/战争积累
- 不满度 ≥ 80 时可**叛变**→ 脱离王国成立独立政权（如「暴风反抗军」）
- 连锁效应：邻近不满村庄概率一并脱离

## 📁 项目结构

```
worldbox/
├── index.html          # 入口页面，加载所有 JS/CSS
├── css/
│   └── style.css       # 全局样式（像素游戏 UI 主题）
├── js/
│   ├── noise.js        # 噪声算法（mulberry32 随机种子 + ValueNoise fBm）
│   ├── world.js        # 世界引擎（地块定义/生成/火焰/熔岩/火山/植被）
│   ├── civ.js          # 文明系统（种族/单位AI/村庄/王国/战争/同盟/叛变）
│   ├── powers.js       # 神力工具（26 个工具 + 爆炸/闪电通用效果）
│   ├── render.js       # 渲染器（像素精灵生成/地图缓存/相机/小地图）
│   ├── ui.js           # UI 层（工具栏/面板/设置弹窗/快捷键）
│   └── main.js         # 主程序（Game 状态/循环/输入/存档）
├── test/
│   └── sim-test.js     # 无头冒烟测试（Node.js 运行核心模拟）
└── .gitignore
```

**模块依赖顺序**：`noise` → `world` → `civ` → `powers` → `render` → `ui` → `main`

所有 JS 均通过全局变量/函数共享，按 `<script>` 标签顺序加载。

## 🛠️ 技术栈

| 层 | 技术 |
|----|------|
| 渲染 | Canvas 2D API，`imageSmoothingEnabled = false`（像素风） |
| 噪声 | Value Noise + fBm（手工实现，无外部库） |
| 存储 | `localStorage`（存档 JSON + Base64 编码类型化数组） |
| 存档 | 自定义 `Uint8Array`/`Uint16Array` ↔ Base64 双向序列化 |
| 字体 | Trebuchet MS / Microsoft YaHei / PingFang SC 系统栈 |
| 输入 | 鼠标 + 触摸（双指缩放）+ 键盘快捷键 |
| 测试 | Node.js 直接 `eval()` 拼接 JS 模块，无 DOM 依赖 |
